# Eat-n-Split

Eat-n-Split is a simple application designed to help groups split bills easily and fairly. Whether you're dining out with friends or sharing expenses, this app ensures everyone pays their share.

## Features

- Add participants to a group.
- Input total bill amount and individual contributions.
- Automatically calculate how much each person owes or is owed.
- User-friendly interface for quick and easy use.

## Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/yakolga/eat-n-split.git
    ```
2. Navigate to the project directory:
    ```bash
    cd eat-n-split
    ```
3. Install dependencies:
    ```bash
    npm install
    ```

## Usage

1. Start the application:
    ```bash
    npm start
    ```
2. Open your browser and navigate to `http://localhost:3000`.
3. Add participants, input the bill details, and let the app do the math!
